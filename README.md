# Student Marks Analyzer

A simple Python project that reads student marks from a CSV file and generates a performance report.

## Features
- Reads student records from a CSV file.
- Calculates total marks.
- Calculates average marks.
- Identifies the highest-scoring student.
- Displays the topper's name and marks.

## Technologies Used
- Python
- CSV Module
- File Handling
- Dictionaries and Loops

## Project Structure

```text
student-marks-analyzer/
├── main.py
├── students.csv
└── README.md
```

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Keep `main.py` and `students.csv` in the same folder.
4. Run:

```bash
python main.py
```

## Sample Output

```text
Total: 438
Average: 87.6
Topper: Rohit
Topper Marks: 95
```
